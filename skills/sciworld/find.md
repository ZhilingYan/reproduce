### TASK: find (animal / plant / living thing / non-living thing) ###

For find tasks, apply these specific strategies:

1. Go Where the Category Lives: Animals and plants are usually outside, in the greenhouse, or by the pond; non-living things are everywhere. Teleport or walk there before searching. Apply this at episode start.

2. Verify the Category Before Focusing: A bee hive, an egg, or a seed jar is NOT an animal; air, the agent, doors, and rooms never count. Pick a clear, unambiguous instance (e.g. an adult animal for living thing; a rock or a chair for non-living thing). Apply this before every focus.

3. Focus Is the Answer: The task is completed by 'focus on OBJ' on a correct instance, then following any move-it instruction the task text gives. A wrong focus immediately fails the episode, so when unsure, keep searching instead of guessing. Apply this once a candidate is confirmed.

4. Read the Task Text for Extra Steps: Some variants ask to move the found object to a named container afterwards; do that with pick up / move actions after the focus. Apply this right after a successful focus.
