### TASK: test conductivity ###

For conductivity tasks, apply these specific strategies:

1. Workshop Is the Lab: The battery, wires, and light bulb are in the workshop; bring the test object there. Apply this at episode start.

2. Build the Standard Circuit: Connect battery anode to wire, wire to the test object, test object to another wire, wire to the bulb, bulb back to battery cathode ('connect X to Y' actions). Apply this with all parts in one place.

3. Read the Bulb: Bulb on = conductive, off = nonconductive. Wait one step after completing the circuit before judging. Apply this after wiring.

4. Answer via the Boxes: Place/focus per the task text (usually focus on the object, then put it in the box matching conductive/nonconductive). Follow the task wording exactly. Apply this after the bulb verdict.
