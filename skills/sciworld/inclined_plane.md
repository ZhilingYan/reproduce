### TASK: inclined plane (angle / friction) ###

For inclined-plane tasks, apply these specific strategies:

1. The Setup Is Prepared: The planes and blocks are already set up in the workshop; do not rebuild them. Apply this at episode start.

2. Time the Slides: Put the block at the top, release, and use the stopwatch to time it; repeat for each plane. Shorter time = steeper angle or lower friction. Apply this per plane.

3. Answer per Task Text: Focus on the plane (or the named answer box) that the task asks for — steepest / least friction / named surface — following the task wording exactly. Apply this after both measurements.
